Gaming Website Mobile App

BattleXO

Redesigning a gaming platform into a connected player ecosystem

Role
Product / UI Designer
Platforms
Website + Mobile App
Scope
Product redesign, UX/UI
Focus
Gamification · Engagement · Loyalty · Monetisation

Overview

BattleXO is a gaming platform built around competitive play. I redesigned the entire website and mobile application while introducing experiences that extend engagement beyond gameplay.

Goal

Create an ecosystem where users can play, compete, watch content, earn rewards, shop and stay connected.

The Challenge

The existing experience focused primarily on gameplay. After a match, users had limited reasons to continue exploring or return between matches.

How can BattleXO give players more reasons to stay, return and engage?

The Approach

Build one connected ecosystem around:

Play → Engage → Earn → Return

Five initiatives

  • Complete Website & Mobile Redesign
  • Byte
  • XO Coins
  • XO Pro
  • XO Wallet & Leaderboard
01 — Complete Website & Mobile Redesign

A full product redesign across web and mobile, clearer hierarchy, consistent navigation, and a gaming-focused interface that surfaces matches, tournaments, rewards and progression.

  • Information hierarchy
  • Navigation
  • Match / tournament discovery
  • Visual consistency
  • Rewards / progression visibility
  • Gaming-focused interface
02 — Byte

Short-form gaming content that keeps users engaged between matches.

Flow

Finish Match → Watch Byte → Discover Content → Continue Exploring → Play Again

User value

Stay entertained and discover content without leaving the platform.

BattleXO value

More session time and stronger reasons to return between matches.

03 — XO Coins

Gameplay-based rewards that connect winning with the XO Shop.

Flow

Play → Win → Earn XO Coins → Shop → Return to Play

User value

Gameplay feels more rewarding, wins translate into tangible value.

BattleXO value

Links competition directly to the shop and repeat play loops.

04 — XO Pro

Premium membership for competitive players, an upgrade to the overall BattleXO experience.

  • 2% XO Shop discount
  • XO Pro badge
  • Up to 2 Scrim participations
  • Up to 10 Rivalry Zone participations
  • Partnered LAN events
  • Giveaways
  • Esports causes
  • Premium tournaments
05 — XO Wallet

A central place to view and manage accumulated rewards and wallet activity.

  • Reward visibility
  • Balance / value
  • Transactions
  • Connection between gameplay and rewards
06 — XO Leaderboard

Makes player performance and competition visible across the platform.

  • Progression
  • Motivation
  • Recognition
  • Competitive engagement

Connecting Everything

  1. PLAY
  2. Win
  3. EARN XO Coins
  4. TRACK XO Wallet
  5. COMPETE XO Leaderboard
  6. SPEND XO Shop
  7. ENGAGE Byte
  8. UPGRADE XO Pro
  9. PLAY AGAIN

Outcome

The shift: from a gameplay-focused platform to a connected gaming ecosystem.

For users

More ways to engage

More reasons to return

More value from gameplay

For BattleXO

More engagement opportunities

Stronger retention loops

New monetisation opportunities

Stronger player loyalty

I redesigned BattleXO across web and mobile and expanded it from a gameplay-focused platform into a connected gaming ecosystem where players could play, watch, compete, earn and spend, all within the same experience.
